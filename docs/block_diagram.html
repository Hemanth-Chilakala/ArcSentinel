ArcSentinel — Data Path, Mixed-Criticality Partition & Timing

How each power cycle travels from the ADC to a trip decision, and why each function lives where it does
Track 2 · PolarFire® SoC Icicle Kit (MPFS250T)
Team ArcSentinel: Hemanth Chilakala (lead), Tanmaya Kumar · v1.1
A. Per-cycle fabric pipeline every 20 ms per channel (50 Hz); everything runs in parallel, no CPU involvement

1 · Capture

8 channels sampled in lock-step at 25.6 kS/s; clock disciplined to PTP time
jitter < 10 ns

2 · Condition

Calibration, residual current Ia+Ib+Ic, source MUX (ADC or replay)
1 sample of latency

3 · Spectrum

CoreFFT 512-pt per cycle per channel → h1–h25 + interharmonic energy
~6 µs / FFT @ 100 MHz*

4 · Arc features

Haar DWT HF energy, half-cycle asymmetry, cycle-to-cycle randomness, h3 angle
streaming, 0 extra passes

5 · Window stats

Mean / σ of 14 features over a 10-cycle window, hop 2 cycles → 28 inputs
< 1 µs

6 · Classify

int8 MLP 28-32-16-7, 1,520 MAC, weights in LSRAM, 16 parallel MACs
~1 µs*

7 · Decide

Bare-metal hart: 5 consecutive HIF windows → alarm / trip; inrush blocking
median 0.28 s after onset

8 · Report

GOOSE over PRP, COMTRADE record, HMI, PTP timestamp
< 4 ms to wire

TRIP output

B. Three independent layers of protection our core novelty vs prior HIF devices

Layer 1 — FPGA fabric (safety-critical, hard real-time)

Sampling, feature extraction, int8 inference and classic overcurrent protection run as dedicated logic. No shared caches, interrupts or scheduler, so latency is identical every cycle. If every processor halts, overcurrent protection still trips the breaker.

Layer 2 — Bare-metal U54 hart (deterministic decision)

Applies security logic to the fabric’s per-window scores: persistence counters, inrush and switching blocking, alarm-versus-trip policy. Runs from L2 scratchpad with no OS, isolated from Linux by PMP and AMP context separation.

Layer 3 — Linux on 3 U54 harts (communications, non-critical)

IEC 61850 GOOSE/MMS, PRP redundancy on both GbE ports, PTP, COMTRADE, web HMI and signed updates. A Linux crash or network attack cannot block a trip; the E51 monitor restarts the context.
